# Leon Jr — Portfolio

Live portfolio: https://bananashakes.github.io/

Personal portfolio featuring an interactive project sphere, six projects, original marker navigation, project explanations and contact links.

The root index.html is self-contained and can be opened directly in a modern browser. It embeds fonts, images, CSS and JavaScript. .nojekyll keeps GitHub Pages from treating it as a Jekyll project. No build or installation is required.

Bundled font notices are in FONT-LICENSES.txt.
