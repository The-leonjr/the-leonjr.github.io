# Leon Jr — Portfolio

Portfolio: https://the-leonjr.github.io/

Personal portfolio featuring an interactive project sphere, six projects, original marker navigation, project explanations and contact links.

The root index.html is self-contained, with embedded images, fonts, styles and JavaScript. No build is required. .nojekyll keeps GitHub Pages from treating it as a Jekyll project. Bundled font notices are in FONT-LICENSES.txt.
